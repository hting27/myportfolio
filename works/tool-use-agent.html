Everyday Assistant: A Tool-Use Agent

2026-11-09 | Python, Gradio, LLM, Tool Use

Overview

This is an assignment for my AI Agents course, built around the Tool Use design pattern. Users ask questions in natural language, and the LLM decides whether a tool is needed and which one to call, then answers based on the tool's output. The agent currently provides three tools: a calculator, a current-time lookup by city, and a BMI calculator.

Tech Stack

  • Python and Google Colab
  • aisuite to call large language models hosted on Groq
  • Gradio for the web user interface

How It Works

  1. Tool selection: The LLM reads the tool descriptions and outputs the chosen tool and its arguments as JSON, for example {"tool": "bmi", "args": {"height_cm": 170, "weight_kg": 65}}.
  2. Tool execution: The program parses the JSON and calls the corresponding Python function to do the actual computation, so the model does not have to do the arithmetic itself.
  3. Response generation: The tool result is passed back to the LLM, which composes a natural-language reply. If no tool is needed, it answers directly.

Reflections

Building this agent showed me that the key to Tool Use is a division of labor: the LLM handles the reasoning and the code handles the computation. Language models are not always accurate with numbers, but they are good at understanding a question and choosing the right tool. Combining the two makes the answers far more reliable.
