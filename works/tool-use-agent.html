生活小幫手：Tool Use Agent

2026-11-09｜Python、Gradio、LLM、Tool Use

專案簡介

這是 AI Agent 課程的作業，選擇的設計模式是 Tool Use。使用者用自然語言提問，AI 會自己判斷要不要用工具、要用哪一個，再根據工具算出的結果回答。目前提供三個工具：計算機、查詢城市現在時間、計算 BMI。

使用技術

  • Python 與 Google Colab
  • aisuite 串接 Groq 上的大型語言模型
  • Gradio 建立網頁操作介面

運作方式

  1. 選工具：AI 讀取工具說明後，以 JSON 輸出要用的工具和參數，例如 {"tool": "bmi", "args": {"height_cm": 170, "weight_kg": 65}}。
  2. 執行工具：程式解析 JSON，呼叫對應的 Python function 實際計算，避免模型自己算錯。
  3. 整理回答：把工具結果交回給 AI，用自然的中文回覆使用者；不需要工具時就直接回答。
def tool_agent(prompt):

心得

做完才發現，Tool Use 的重點是讓 AI 負責「判斷」，讓程式負責「計算」。語言模型算數字不一定準，但很擅長看懂問題、選出合適的工具，兩者搭配起來答案就可靠多了。
