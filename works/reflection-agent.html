Social Media Post Reflection Agent

2026-10-29 | Python, Gradio, Reflection

Overview

A Reflection agent implemented with reference to course example Demo07a. The user describes something they want to share today; the LLM writes a first draft of a social media post, switches to a "reviewer" role to suggest revisions, and then rewrites the post into a second version based on that feedback.

Tech Stack

  • Python and Google Colab
  • aisuite to call large language models hosted on Groq
  • Gradio for the web user interface

How It Works

  1. Drafting: The writer role generates the first version of the post from the user's input.
  2. Reviewing: The reviewer role checks whether the post sounds natural and conversational, and gives concrete suggestions.
  3. Revising: The writer role produces a second version based on the suggestions. The interface displays the output of all three stages side by side.

Reflections

Adding a single self-review step usually makes the second version much more natural than the first. It also showed me that assigning the LLM different roles lets it evaluate the same content from different perspectives.
