Three AI Agent Design Patterns

2026-11-05 | AI Agents, Course Notes

Key Points

PatternApproachBest Suited For
ReflectionGenerate an output first, then critique and revise itWriting, editing and other tasks where output quality matters
Tool UseSelect and call tools as needed, such as a calculator, web search or custom functionsQuestions that require precise computation or up-to-date data
PlanningBreak the task into steps first, then execute the plan step by stepComplex, multi-step tasks that require sequencing

Examples

  • Reflection: Write a social media post, review it, and rewrite it as a second version.
  • Tool Use: Ask "Four people spent NT$2,380 plus a 10% service charge. How much does each person pay?" and the agent uses a calculator instead.
  • Planning: Plan a three-day trip by first listing what to do each day, then working out the details day by day.

My Takeaways

All three patterns compensate for weaknesses of language models: Reflection addresses "rarely gets it right on the first try," Tool Use addresses "inaccurate arithmetic and outdated knowledge," and Planning addresses "missing steps in large tasks." In practice, they are often combined.
